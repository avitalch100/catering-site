# אתר קטלוג קייטרינג

אתר קטלוג מלא המחובר ל-Airtable: מצ ג את המוצרים והקטגוריות בזמן אמת,
בודק זמינות תאריכים מול טבלת ההזמנות, ושומר הזמנות חדשות ישירות ב-Airtable.

## מבנה הפרויקט

- `pages/index.js` — עמוד הקטלוג (התצוגה שהלקוחות רואים)
- `pages/api/catalog.js` — פונקציית שרת שמביאה קטגוריות/מוצרים/תאריכים תפוסים מ-Airtable
- `pages/api/orders.js` — פונקציית שרת ששומרת הזמנה חדשה ב-Airtable
- ה-Token הסודי נשמר **רק** במשתני סביבה בצד השרת — אף פעם לא בקוד הצד-לקוח

## הרצה מקומית (אופציונלי, לבדיקה לפני העלאה)

1. התקיני חבילות: `npm install`
2. העתיקי את `.env.local.example` לקובץ בשם `.env.local` ומלאי בו את ה-Token שיצרת
3. הריצי: `npm run dev`
4. פתחי `http://localhost:3000`

## העלאה לאוויר (Vercel) — שלב אחר שלב

### 1. להעלות את הקוד ל-GitHub
1. היכנסי ל-[github.com](https://github.com) וצרי חשבון אם אין לך
2. לחצי "New repository", תני לו שם (למשל `catering-site`), ולחצי "Create repository"
3. את יכולה להעלות את הקבצים דרך הממשק של GitHub עצמו (גרירה של כל התיקייה) —
   אין צורך בשורת פקודה אם לא נוח לך עם זה

### 2. לחבר ל-Vercel
1. היכנסי ל-[vercel.com](https://vercel.com) והתחברי עם אותו חשבון GitHub
2. לחצי "Add New… > Project"
3. בחרי את ה-repository שיצרת
4. **לפני שלוחצים Deploy** — פתחי את "Environment Variables" והוסיפי:
   - `AIRTABLE_TOKEN` = ה-Token שיצרת ב-Airtable (מתחיל ב-`pat`)
   - `AIRTABLE_BASE_ID` = `appK4L26DfUKE5MtM`
5. לחצי "Deploy"
6. אחרי דקה-שתיים האתר יהיה חי בכתובת שVercel נותנת (למשל `catering-site.vercel.app`)

### 3. דומיין מותאם אישית (אופציונלי)
ב-Vercel, תחת Project Settings > Domains, אפשר לחבר דומיין שכבר יש לך,
או לרכוש אחד ישירות דרך Vercel.

## עדכון תוכן

כל תוכן הקטלוג (מוצרים, מחירים, תמונות, קטגוריות) מנוהל **ישירות ב-Airtable** —
כל שינוי שם מופיע באתר תוך רגע, בלי צורך לגעת בקוד או לפרסם מחדש.

הזמנות חדשות מהאתר נשמרות אוטומטית בטבלת "הזמנות" ב-Airtable.
